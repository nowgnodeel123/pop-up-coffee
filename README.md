# 팝업 커피 (Pop-up Coffee) ☕

팝업 스토어의 효율적인 운영을 돕기 위해 개발된 재고 관리 및 판매 시스템입니다. 실시간으로 변동되는 재고를 파악하고, 원활한 판매 프로세스를 지원하여 관리자와 고객 모두에게 편리함을 제공하는 것을 목표로 합니다.

<br>

## 🚀 주요 기능

- **실시간 재고 관리**: 상품의 입고 및 출고를 기록하고, 현재 재고 수량을 실시간으로 추적합니다.
- **주문 및 결제 처리**: 고객의 주문을 접수하고, 포인트 기반의 간편 결제 기능을 제공합니다.
- **매출 및 통계**: 일별, 상품별 매출 현황을 집계하고 간단한 통계 정보를 제공하여 판매 전략 수립을 돕습니다.
- **포인트 시스템**: 고객의 포인트를 충전하고, 결제 시 사용할 수 있도록 관리합니다.
